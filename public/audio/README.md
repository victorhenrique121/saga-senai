# Áudios de ronco

Esta pasta contém os áudios locais licenciados usados pelo catálogo:

- `golf.mp3`
- `civic.mp3`
- `opala.mp3`
- `bmw.mp3`

O catálogo usa os caminhos públicos `/audio/<veiculo>.mp3`. Se um arquivo estiver ausente em uma futura atualização, a interface apresenta um alerta recuperável ao visitante sem interromper a aplicação.
